This directory is a checked-in compatibility placeholder, not official Convex-generated output.

After an operator configures and authenticates a real deployment, run `npx convex dev` or `npx convex deploy` and commit the regenerated `_generated/` files. Until that external provisioning gate is complete, local Convex tests use convex-test only; they do not prove deployed Convex HTTP or browser end-to-end behavior.
